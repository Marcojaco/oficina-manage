# ✅ Criado AppError

Arquivo:

```
src/errors/AppError.js
```

Implementado:

* [x] Classe personalizada de erro.
* [x] Herança da classe `Error`.
* [x] Adicionado `statusCode`.
* [x] Adicionado nome personalizado.

Uso:

Antes:

```javascript
const erro = new Error();
erro.status = 404;
throw erro;
```

Agora:

```javascript
throw new AppError(
    "Cliente não encontrado",
    404
);
```
